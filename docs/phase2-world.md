# Phase 2: Reveal World
Only Reveal World and the durable Visual World Report contract are implemented.
The report includes mood, emotional arc, visual language, cinematography, environments, color/lighting, motifs, atmosphere, movement, continuity rules, and immutable continuity.
Confirmation is persisted with "Yes, that's my world." in world_reports and projects. The browser calls only beatvision-world; provider configuration remains server-side.
Missing/unimplemented providers produce an explicit unavailable state and never fake a report.
Style Bible, characters, storyboard, scenes, motion, and image generation are not implemented.
