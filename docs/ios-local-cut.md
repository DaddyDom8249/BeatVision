# BeatVision iOS — Local Cut (no provider billing)

**Status:** iOS source integration; Xcode and signed device build NOT VERIFIED.

## What this does

This retains BeatVision's existing React/Vite app, Supabase auth, owner-scoped reads, Vision Lock, song/World/Style/Scene flows, and the generation controller's zero-cost guard. It does **not** make a new backend or bypass provider cost checks.

The new `/projects/:projectId/local-cut?plan=:approvedPlanId` view:
- Reads approved scene boundaries only through existing Supabase owner-scoped queries.
- Imports a matching audio file and user-owned still images or video clips **locally**. It never uploads these local files or writes creative state.
- Uses the approved scene timeline to preview the images/clips against the song.
- When all scenes use still images and the browser supports `canvas.captureStream` and `MediaRecorder`, encodes a 720p real-time local animatic with original audio. No paid AI or remote assembly service is used.
- Rejects a mismatched duration, timeline gap/overlap or unsupported encoding, instead of falsely reporting success.
- Explicitly does not claim to generate AI pictures or motion, persist approved assets, or replace final_videos.

**Limitations:** Imported video clips are preview-only. A local video export may not be supported by every iOS WKWebView/codec. The browser's download link may need a native Files/share extension for reliable saving on iOS. The render runs in real time and must remain in foreground. Long song processing, low-memory devices and browser audio synchronization remain unverified. This is not yet a durable provider-free production final-video pipeline.

## Add the real iOS platform (requires a Mac + Xcode)

```bash
npm install
npm run build
npx cap add ios
npx cap sync ios
npx cap open ios
```

Build and run the `App` target in Xcode on a simulator and a physical iPhone; verify authentication, approved plan access, local file picker, preview, the actual encoded video bytes, Files export and background/interruption behavior before TestFlight. Capacitor 8 requires a supported Xcode toolchain. Confirm current requirements from the official Capacitor docs.

Do not check generated signing material or developer credentials into Git. The `ios/` native project is generated by `cap add ios`; it has not been generated or compiled in the current non-macOS environment. The app bundle identifier in `capacitor.config.ts` must be checked in Apple Developer provisioning before App Store submission.

## Security and approval invariants

- New images and assembly jobs still stop with `PROVIDER_COST_UNVERIFIED`; this restriction is intentional until their **actual execution path** is verified zero-cost.
- No project, audio, approvals, asset rows, `generation_jobs`, RLS, storage or migrations are modified by Local Cut.
- Local export is an unapproved **manual animatic**, not a canonical `final_videos` row; it cannot be used to bypass owner or Vision Lock checks.
- No Xcode/device build, local export on an actual iPhone, provider call, paid action, migration or production deployment was performed by this change.

## Smoke test sequence

1. Sign in with existing account.
2. Open a project with an approved Visual Plan and verify the correct plan ID/scenes.
3. Open Production Workspace → Local Cut.
4. Select the exact song and an image for each scene.
5. Preview all scene boundaries with the timeline.
6. Export locally if the codec and capture APIs are supported.
7. Verify decoded bytes and audio/video duration, not just a nonempty Blob.
8. Verify mismatch, unsupported codec, unauthorized project and imported-video fallback errors.
